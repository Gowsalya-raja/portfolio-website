# Personal Portfolio Website
 
A simple and responsive personal portfolio website built using *HTML5 and CSS3*. The website introduces my professional profile and provides a way for visitors to contact me.
 
## 🌐 Pages
 
- *Home* – Introduction and personal profile
- *Contact* – Contact information and communication section
 
## 🛠️ Technologies Used
 
- HTML5
- CSS3
 
## ✨ Features
 
- Clean and simple user interface
- Responsive design
- Semantic HTML structure
- Custom CSS styling
- Easy navigation between pages
- Beginner-friendly and lightweight implementation

The objective of this project is to create a professional online presence, showcase my technical background, and continuously improve my frontend development skills.
